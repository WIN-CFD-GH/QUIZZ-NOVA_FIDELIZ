# 📂 Directorio de Respaldos (Backups)
## MISIÓN WINNER - NOVA FIDELIZ - QUIZZES

En este directorio se almacenan los respaldos periódicos del banco de preguntas y de las evaluaciones registradas.

### Formatos Soportados:
1. **JSON Full Backup (`.json`):** Contiene la estructura completa de preguntas, evaluaciones, usuarios y configuración.
2. **Excel Export (`.xlsx`):** Contiene la data tabular de resultados para auditorías e importación masiva de preguntas.

Los respaldos se pueden generar y restaurar directamente desde el **Hangar del Banco de Preguntas** (`banco_preguntas.html`) y el **Dashboard** (`dashboard.html`).
